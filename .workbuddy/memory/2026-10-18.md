## FSToast 最后一个 UIKit 实现清掉

`FSToast.toast(_:duration:to:)` 原来是 `UILabel` + `UIView` 手搓：量文字宽高（`FSCalculator`）、
造 label、造深灰圆角块、`addSubview` 到宿主、两段 `UIView.animate` 淡入淡出、延时移除。
现改为一行转发 `FSToastCenter.shared.show(text, duration:)`，**与不带 `to:` 的调用同一条路径**。

- `to:` 参数保留（类型 `UIView` → `AnyObject?`），内容**忽略**：93 处调用点一行不用改。
  `_ =` 写法仍编译通过（只多一条 "`_` on Void is redundant" 警告，与现存的
  `_ = FSToast.toast("换组成功")` 同类，不是新问题）。
- 文件不再 import UIKit 相关类型，`FSCalculator` / `WIDTHFC` 依赖一并消失。
- 行为变化 1 处：toast 从「宿主 view 居中」变成「屏幕居中」（`AppRootScreen` 的
  `FSToastOverlay` 是全局浮层）。`to:` 传值不再影响任何东西。

校验：用桩 `FSToastCenter` 建了 `/tmp/toastcheck/FSKit.swiftmodule`，
`swiftc -typecheck` 跑通 FSToast.swift + 五种旧调用写法（含 `to:` 传非可选/可选/`_ =`）。
**纯源码校验，未跑 xcodebuild 构建。**

待办（已完成）：`open class FSToast: NSObject` → **`open class FSToast`**（已去掉 NSObject 继承）。
全仓库 + 宿主 App 只有 `FSToast.toast(...)` 静态调用（FSShare.swift 2 处、AppRootScreen.swift 3 处），
0 实例化、0 子类、无 `@objc`/`super` 依赖，所以删继承是安全的。未改 `open` 为 `enum`（保持最小改动），
以后想彻底工具化可再换 `public enum FSToast`。**纯源码改动，未跑构建。**
