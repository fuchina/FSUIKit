## `showAlertWithMessage` / `showAlertWithTitle` 的 handler 改为可选

`FSUIKit/Classes/Swift/FSUIKit.swift`：
- `showAlertWithMessage(_:handler:)` → `handler: ((UIAlertAction) -> Void)? = nil`
- `showAlertWithTitle(title:message:ok:handler:)` → 同样加 `= nil`

调用方可直接 `FSUIKit.showAlertWithMessage("xxx")`，不必再传 `handler: nil`；
既有传 nil 的调用点（`FSShare.swift` 153/186/223 三处）二进制/源码兼容，一行未动。

注：可选闭包作最后一个参数，trailing closure 写法也合法：
`FSUIKit.showAlertWithMessage("xxx") { _ in }`。
